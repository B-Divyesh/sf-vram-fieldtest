# VRAM Field Test — visual system

## Direction: cassette-era zine

This is a diagnostic record, not a dashboard. The site borrows from service-bench cassette labels: warm newsprint, dense black ink, safety-orange test marks, cobalt tape-window blue, and square registration dots. It makes a technical report feel like a physical item a resale shop can attach to a card.

## Tokens

- `paper` `#f4ead6` — single light-mode background, deliberately fixed.
- `ink` `#181714` — primary text and outlines.
- `muted` `#4d493f` — secondary text.
- `orange` `#b83212` — primary action and warning marks.
- `blue` `#12587d` — tape-window panels and links.
- `acid` `#d6df54` — verification labels.
- `pass` `#176a44`; `fail` `#9c251d`.

Ink on paper and paper on orange meet the required contrast. The product intentionally uses a single paper treatment rather than a theme switch: this is a scanned zine sheet, not a floating app.

## Type and rhythm

Headlines use the system monospace stack (`ui-monospace`, Menlo) for equipment labels. Body uses the local system sans stack for legible instructions. Scale is 8px-based; copy stays in a 68-character measure. Squared labels, double borders, dot grids, and offset orange shadows are the shape language.

## Motion

The tape-window progress bars advance once on entry (220ms) to explain a running memory pass. There are no loops. With reduced motion, bars render at their final width and page transitions are instant.

## Assets and provenance

`site/public/hero-vram-small.webp` is an original generated editorial still: an anonymous repair bench with a black GPU, transparent memory chips, a labelled cassette, and no readable text or logos. Generated by `/opt/fleet/lib/gen-image.sh` using deployment `factory-image`; prompt is stored beside it in `hero-vram.png.json`. It is decorative, has empty alt text, and is 121 KB after local WebP optimization. `site/public/social.svg` is hand-composed from the same palette for metadata and does not contain required information.

The Report Kit keeps the same physical-record language. Double ink rules form the printable cover; dashed cuts distinguish batch labels. Print styles remove navigation and shadows so the artifact remains legible on plain paper.
